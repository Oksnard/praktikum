# План и фактический объём

## Задача и допущения

Компания превращает рабочий материал в практическое задание. Сотрудник отвечает развёрнуто; руководитель видит критерии, цитаты, пробелы и персональное обучение. Общий баланс компании и индивидуальные накопительные лимиты защищены транзакциями. 1 кредит=1microUSD внутреннего тарифа по usage с округлением вверх на вызов; реальные платежи вне MVP. AI рекомендательный, решения принимает человек.

Владелец регистрирует компанию и создаёт менеджеров/сотрудников. Материал и задания общие внутри компании, попытки персональные; менеджер/владелец видят командный отчёт. SUPER_ADMIN — отдельный платформенный финансовый аудит. Tenant всегда из сессии, не параметра браузера.

## Последующие согласованные дополнения

- DeepSeek вместо первоначального OpenAI: JSON mode+локальная Zod/evidence валидация, optional OpenAI strict adapter; резерв200000, cache usage, внутренний тариф. ADR0010.
- Временная публикация по HTTPS с Mac через Cloudflare Tunnel и закрытый gate, отдельная review БД/пользователь и случайные app-пароли. По уточнению заказчика регистрация включена **за gate**; новая компания начинается с0. Постоянный VPS не развёрнут.
- Word DOCX/DOC, PDF с текстовым слоем и TXT: извлечение, проверка, private оригиналы, tenant download. OCR не входит; лимиты и отклонения видны пользователю.
- Первый визит: подсветка разделов и объяснения с учётом роли, пропуск/повтор/клавиатура/мобильная версия.
- Unit, HTTP e2e, Playwright Chromium, реальный AI на опубликованном HTTPS, аудит ТЗ/архитектуры/документов, paired backup/restore.
- Безопасная очистка только воспроизводимых кэшей/временных артефактов. Проект с историей Git публикуется в приватный GitHub без секретов/БД.

## Границы и риски

Один кейс на материал, фиксированный snapshot критериев; нет реальных платежей/email/SSO/reset password. Application-level tenancy требует проверки каждого нового запроса; RLS не заявлен. Нет автоматической сверки UNKNOWN/PENDING после неопределённого внешнего исхода. Семантическая правильность всех AI ответов не доказана пятью evals. Временный Mac URL зависит от процессов и сети; постоянное размещение, offsite backup, OCR и массовая обработка файлов требуют отдельного этапа. Регистрация и Demo пополнение в обычном production по умолчанию выключены, в закрытой review среде включены явно.
