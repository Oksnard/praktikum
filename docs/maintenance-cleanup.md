# Безопасная очистка Mac — 2026-11-24

По запросу заказчика удалены только воспроизводимые кэши: неиспользуемые npm exec packages, pnpm metadata/download cache, Xcode build/index/module caches, сетевой/code/GPU cache браузеров и Codex. Активные package runtimes, Playwright Chromium, базы, проекты, исходники, секреты, login/session storage и Docker volumes сохранены. Собственная старая Next сборка удалялась при остановленном dev-сервере, затем production сборка создана заново.

Зафиксировано непосредственно до/после широкой очистки:220МиБ →4404МиБ свободно; логический размер удалённых файлов3920МиБ. По группам: inactive npm1266.3МиБ, pnpm291.4МиБ, Xcode877.7МиБ, browser cache1485.2МиБ. Физический выигрыш отличается из-за особенностей APFS и параллельных записей. После новых сборок и тестов оставалось около3.1ГиБ. Машинный локальный отчёт `.runtime/cleanup-report.json` не является постоянным мониторингом.

Docker Desktop не установлен: `/Applications/Docker.app` отсутствует, `docker` — неработающая ссылка, engine socket не найден. Поэтому подключиться к engine и подтвердить/удалить контейнеры нельзя. Никакой `docker system prune --volumes` не выполнялся. Не удалялись неизвестные VM-диски или каталоги данных.

Для повторной очистки сначала проверить работающие процессы и свободное место. Не удалять `.runtime/postgres`, `.runtime/review`, активную `.next`, пользовательские документы или volumes ради освобождения места. Временная ссылка и данные review зависят от этих runtime файлов. `pnpm store prune`/`npm cache clean --force` могут потребовать повторной загрузки пакетов; это очищает cache, а не зависимости проекта.
