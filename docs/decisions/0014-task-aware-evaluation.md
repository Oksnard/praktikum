# ADR0014 — Task-aware assessment V2

Статус: accepted implementation; ограниченная live semantic acceptance V2 PASS, legacy new grading closed.

Причина: в живом QA общий промпт штрафовал допустимые планы и объявлял явно названные действия пропущенными. Три попытки по1500 output tokens не позволяли закончить полный отчёт.

Решение: в том же вызове генерации сохранять требования конкретного вопроса; оценивать их с answer quotes и полным source/criteria контекстом. Версионировать JSON и cache; читать исторические данные без миграции и без переписывания provenance. Расширить output до4096 и ограничить полный запрос до резервирования. Никаких дополнительных платных critic calls, автоматического ослабления score bands или отраслевых словарей.

[Контракт, формула резерва, совместимость, проверки и ограничения](../ai-evaluation-design.md). [Фактическая семантическая приёмка](../ai-quality-review.md).

Legacy regression88 сформировалась без обрыва, но содержала ложные штрафы. Принято решение не строить рубрику после просмотра ответа: новые оценки старых заданий409 без списания, управляющий создаёт новоеV2задание; прежние результаты остаются read-only. [Подробная история и результаты](../ai-quality-review.md).
