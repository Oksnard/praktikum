# 0009. Opaque server sessions

Статус: accepted
Дата:2026-11-24

## Контекст и решение
256-bit random tokens, SHA256 хеши в БД,24h expiry, logout revoke. Пароли scrypt+randomsalt через node crypto, без стороннего JWT и дублирования проверки роли. Next proxy — optimistic UI check; API — authoritative DB check.

## Альтернативы и последствия
JWT усложняет отзыв и изменения полномочий. Нет SSO/password reset/rate limiting, только ограниченный локальный MVP.
