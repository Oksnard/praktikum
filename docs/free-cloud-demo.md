# Бесплатный облачный стенд для одного показа

## Цель и текущее состояние

25.11.2026 заказчик запросил бесплатное размещение в интернете для одного показа. Выбран Render: один Web Service `free` и отдельная PostgreSQL `free`. Создание ресурсов и публичная доступность ещё не подтверждены. Для развёртывания требуется авторизованное подключение Render; локального доступа к GitHub недостаточно. Платные сервисы, диски и обновления тарифа не разрешены.

Действующая ссылка с Mac остаётся в [deployment](deployment.md). Она не является доказательством облачного развёртывания. Новая облачная БД должна быть пустой; база и документы с Mac не переносятся.

## Что разворачивается

Существующие NestJS API и Next.js запускаются на loopback внутри одного сервиса. Наружу выходит только HTTPS review gateway с общим паролем; далее работают обычные сессии, роли и изоляция компаний. Секреты провайдера AI и доступы передаются только через переменные окружения Render. Реальный DeepSeek остаётся за существующим интерфейсом; подмены результата AI нет.

Бесплатный диск Render не сохраняет загрузки после перезапуска. Для облачного стенда предусмотрен отдельный провайдер FileStorage на PostgreSQL Bytes; прежний локальный провайдер остаётся по умолчанию. Оригинал файла по-прежнему выдаётся только после проверки компании текущей сессии. Бесплатная БД ограничена 1 ГБ, поэтому стенд предназначен для небольшой демонстрации.

## Ограничения бесплатного тарифа

[Render Free](https://render.com/docs/free): web засыпает после 15 минут без запросов; первый запрос после простоя может ждать примерно минуту. Бесплатная PostgreSQL истекает через 30 дней. Локальный диск не считается постоянным хранилищем. У сервисов и базы явно выбирается `free`; отсутствие поля тарифа недопустимо, поскольку тариф по умолчанию может быть платным. Учётная запись с платёжным методом требует проверки ограничения расходов до создания ресурсов.

Перед показом открыть ссылку и дождаться страницы входа. Публичную ссылку, проверку входа, регистрации, загрузки/скачивания, хранения после перезапуска и финансовых ограничений записать после реального развёртывания. Build, Blueprint и тесты сами по себе не означают публикацию.
