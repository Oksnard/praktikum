# Обучение при первом посещении

После входа кабинет автоматически запускает короткий тур через250мс. Доступные разделы подсвечиваются, рядом показаны назначение и следующий шаг. Владелец видит5 шагов: обзор, материалы/задания, результаты, команда/лимиты, финансы. Менеджер и сотрудник видят по4 доступных им шага; платформенный администратор —4 шага финансового аудита. Несуществующие/недоступные цели пропускаются. Полные тексты — `apps/web/src/app/onboarding-tour.tsx`.

Кнопка «Обучение» (`aria-label="Запустить обучение снова"`) доступна в закреплённой верхней панели кабинета и админки. Она не плавает поверх формы и на390px не перекрывает кнопки действий. В туре есть «Назад», «Далее», «Готово», крестик с именем «Пропустить обучение» и Escape. После завершения/пропуска фокус возвращается к кнопке. Поддерживается reduced motion; текст статический и не содержит пользовательского HTML.

Первый визит учитывается **для пользователя в этом браузере**: localStorage `praktikum:onboarding:v1:<userId>` со значением `seen`. Другой пользователь, браузер или устройство увидит тур заново; очистка localStorage тоже запускает его вновь. При недоступном storage используется память вкладки, поэтому после перезагрузки показ может повториться. Это не серверная отметка прохождения и не глобальная блокировка по компании.

Реализация: driver.js1.14.0, отдельный client component и локальные CSS, основные страницы остаются Server Components. Таймер очищается при ручном запуске/unmount, экземпляр driver уничтожается. Стили popup ограничены этой подсказкой. Источники Context7 `/websites/driverjs`: [конфигурация](https://driverjs.com/docs/configuration), [шаги](https://driverjs.com/docs/async-tour), [стили](https://driverjs.com/docs/styling-popover).

Проверено Playwright: первый визит, переходы/назад, пропуск и Escape, повтор кнопкой, отсутствие автоматического второго показа после перезагрузки, employee/owner targets. На390×844 все5 шагов владельца, закрытие и next/done полностью в viewport, нет горизонтального переполнения. Дополнительно первый визит/повтор/мобильный тур прошли на действительной публичной HTTPS версии. Отчёт — [browser-tests.md](browser-tests.md).
